## New this session that the next one should know

- **`Stx.Core.Logging.ErrorLog`** is where background failures go (`%LOCALAPPDATA%\STXDownloader\logs\errors.log`).
  Each test project points it at `%TEMP%\stx-tests\<project>\errors.log` (`TestErrorLog.cs`), so tests never write
  into a real user's log.
- **One row per path** is now the catalog's rule (`ICollectionCatalog.AddLocal`), and migration step 4 merged old
  duplicates. Any new writer of `media_files` should keep to it.
- **`Directory.Packages.props`** holds every package version; a project's `PackageReference` names no version.
- **Warnings are errors** solution-wide. xUnit's analyzers count: a test that blocks on a task (`.Wait()`) fails the build.
- **The tool updater has its own HTTP client** with redirects off (`ToolManager.NewHttpClient`); it follows them itself,
  each held to `ToolVersions.UpdateHosts`.
